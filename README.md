# 🏜️ Marrakech Tourism

A modern tourism booking platform built with Laravel for discovering and booking experiences in Marrakech, including Agafay Desert and Palmeraie.

## ✨ Features

- Tour booking
- Camel ride reservations
- Quad bike activities
- Contact form
- Customer authentication
- Responsive design
- Admin dashboard

## 🛠️ Technologies

- Laravel
- PHP
- MySQL
- Bootstrap
- JavaScript
- HTML5
- CSS3
